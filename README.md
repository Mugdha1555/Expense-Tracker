# 💰 Expense Tracker

> A modern full-stack expense management application featuring secure authentication, budget tracking, interactive analytics, income & expense management, CSV export, and a responsive user interface.

---

## 🚀 Overview

Expense Tracker is a full-stack personal finance management application that helps users monitor their income and expenses, visualize spending patterns, manage monthly budgets, and gain financial insights through an intuitive dashboard.

Built using **Node.js, Express, MongoDB, HTML, CSS, and JavaScript**, the application provides a clean, responsive experience with secure JWT-based authentication.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Mugdha1555/Expense-Tracker.git
```

Navigate into the project

```bash
cd Expense-Tracker
```

Install backend dependencies

```bash
cd server
npm install
```

Run the backend

```bash
npm start
```

Open the frontend

```
client/pages/index.html
```
